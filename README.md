# CMSC 120 — Lists

The starter for the lists week of CMSC 120, Fall 2026: Pyret's list, in Java.

- `src/Lst.java` — Pyret's list as a Java type: `Lst.of(...)`, `Lst.filter`,
  `Lst.map` and `Lst.fold` in Pyret's order, and `Lst.Empty()` and
  `Lst.Link(first, rest)` for a `switch`. Keep it beside your files and do not
  edit it. The comment at its top says how to use it.
- `src/Check.java` — `Check.is(...)`, as in every Java week; it takes two
  lists too.
- `src/Img.java` — the pictures from the graphics week.
- `pom.xml` — names JavaFX, the library underneath `Img`. IDEA reads it and
  fetches JavaFX. Not yours to change.

## Your own copy

1. On this page, the green **Use this template** button → **Create a new
   repository**. Name it `cmsc-120-lst`, as here, and pick **Private**.
2. In IDEA: the menu button (☰, top left) → **File** → **New** → **Project
   from Version Control…** → paste your new repository's address → **Clone**.
   Log in to GitHub when IDEA asks, and say yes to loading the Maven project.

Your files go in `src/`, beside these. To keep your work: **Git → Commit…**,
tick your files, write a line saying what you did, **Commit and Push**, then
look at your repository on GitHub to see the commit there.
